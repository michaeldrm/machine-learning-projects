# ML Projects

Welcome to the `machine-learning-projects`  repository !

## Projects

### [Project 1: Multiple Linear Regression From Scratch](https://github.com/michaeldrm/lregression-scratch)
- **Description**: Predicting house prices using a linear regression model implemented from scratch
- **Techniques Used**: Linear Regression, Gradient Descent
- **Dataset**: [Housing Prices dataset](https://www.kaggle.com/datasets/yasserh/housing-prices-dataset)

### [Project 2: Breast Cancer Classification](https://github.com/kur0ii/breast-cancer-classification)
- **Description**: A machine learning project to classify breast cancer as malignant or benign using various algorithms.
- **Techniques Used**: Logistic Regression, Decision Trees, Random Forests, Support Vector Machines
- **Dataset**: [Breast Cancer Wisconsin dataset](https://www.kaggle.com/datasets/yasserh/breast-cancer-dataset)
